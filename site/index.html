What it does

It holds when the page changes

Highlights are found again by their words and the words around them, not by a position in the page. So they survive a reply being regenerated, a message being edited, or the whole thread re-rendering. That is the hard part, and it is the reason this works inside a chat at all.

A link to the exact sentence

Every highlight carries an ordinary URL text fragment. Send one to someone who has never heard of Kona and it lands them on the precise words, in any modern browser, on any device. Nothing to install to read it.

One library, searched from anywhere

Alt+Shift+F opens a search over everything you have ever highlighted, without leaving the page you are reading. Filter by site, by tag, by conversation. Picking a result opens it where it came from.

Nothing leaves your computer

No account, no server, no analytics. Kona can only see the three chat sites plus whichever sites you switch on yourself, and you can switch any of them off again. Export to Markdown for Obsidian or Notion whenever you like.

When the sources are the work

Research, a thesis, a literature review, a competitive teardown — the work where a citation has to survive being checked. Kona behaves the same on a paper, a documentation page or a chat; it started with AI conversations only because they are the hardest thing to highlight.

Switch it on for any site

A paper, documentation, Stack Overflow, GitHub, a news archive, a blog you keep coming back to. One click from the toolbar and that site highlights like any other — same colours, same notes, same tags, same one library.

For a thesis or a literature review

When the sources are the work, a citation has to survive being checked. Kona keeps the passage, the page it came from, and a link that lands on the precise words — then exports the lot as Markdown with the links intact, into Obsidian, Notion, or whatever you write in.

One question, many kinds of source

A single space can hold a paper, a documentation page and a chat, because a question does not care where its answer came from. Two independent sources agreeing is worth more than either on its own, and you can see that at a glance.

It outlives the tab

A copy of every highlighted passage is kept alongside it, so you still have the words when the page is rewritten, the article slips behind a paywall, or the conversation is deleted.

Building it yourself — three commands

Node 20 or newer is the only thing you need installed first.

  1. Get the source

    Clone it and install, once.

    git clone https://github.com/aniketpandey05/kona
cd kona
npm install

  2. Build the one you want

    Chrome, Edge and Brave first, then Firefox, then the desktop app. Each writes into .output/ and leaves the others alone. 

    npm run build
npm run build:firefox
npm run build:desktop

  3. Load it

    For the extension, open chrome://extensions, turn on developer mode, and point Load unpacked at the build. The desktop app just runs. 

    # extension: .output/chrome-mv3
npm run start:desktop

The phone app needs none of this — open it and use your browser’s Add to Home Screen.

Three people ask the same question and get three different answers.

Nobody finds out. Everyone has an AI seat now, and everything they produce with it lands in a private history nobody else can search — so the same question gets worked out again next week, slightly differently, by someone sitting ten feet away. Ask a model the same thing twice and you do not even get the same answer back.

What a team shares in Kona is a space: one question, the evidence gathered under it, what is still unknown, and the decision that came out. Each finding names the highlights it rests on — so a space writes itself up as a memo where every claim cites the exact sentence it came from, checkable in one click by someone who has never installed anything.

  • Evidence from chats and the open web, kept by whoever happened to be reading.
  • Findings that disagree are marked as disagreeing, not averaged away.
  • A space can be unfinished — which is what makes it worth opening on Monday.
  • Everything anyone writes in a shared space is signed, so a copy coming back is provably theirs.

The searching part already works, free. Point Kona at a folder your team already shares and the libraries merge both ways, so a search of yours covers every passage anyone has put in a shared space, each one still credited to whoever found it. What the paid tier adds is the part that genuinely needs a server: taking access back from one person, and names your organisation vouches for rather than took on trust.
